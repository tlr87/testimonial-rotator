# Testimonial Rotator

A lightweight WordPress plugin for displaying rotating customer testimonials with configurable transitions, navigation controls, author details, company information, and optional Read More links.

Developed by Tom Revill / RD3 Tech.

## Features

- Custom Testimonial post type
- Testimonial title/author name
- Testimonial content
- Featured image/avatar
- Job title / position
- Company name
- Optional company website
- Optional Read More link
- Fade or slide transitions
- Configurable rotation interval
- Seconds, minutes, hours and months
- Previous/Next navigation arrows
- Navigation dots
- Optional author/title display
- Custom CSS for the Read More button
- Shortcode
- Shortcode copy button in the Testimonials admin screen
- Direct link to plugin Settings from the Testimonials screen
- Mobile swipe support
- Desktop hover pause support

## Requirements

- WordPress 6.x or later
- PHP 7.4 or later
- JavaScript enabled in the browser

## Installation

1. Download or clone the plugin.
2. Copy the `testimonial-rotator` folder to:

   `wp-content/plugins/`

3. Activate **Testimonial Rotator** from:

   `WordPress Admin → Plugins`

4. A new **Testimonials** menu will appear in the WordPress admin area.

## Creating a Testimonial

Go to:

`Testimonials → Add New`

### Title

Enter the testimonial author's name.

Example:

`John Smith`

### Content

Enter the testimonial text.

### Featured Image

Optionally add a customer photograph or avatar.

### Job Title / Position

Example:

`Director`

### Company Name

Example:

`ABC Business Ltd`

### Company Website URL

Optional website address for the company.

If supplied, the company name becomes a link.

### Read More URL

Optional URL for a page containing the full testimonial, case study or related information.

When supplied, a **Read More** button is displayed.

## Shortcode

The standard shortcode is:

`[rotating-testimonials]`

Add this shortcode to any WordPress page, post or supported content area where the testimonials should appear.

## Shortcode Options

The shortcode accepts the following optional parameters.

### Rotation interval

[rotating-testimonials interval="5"]
